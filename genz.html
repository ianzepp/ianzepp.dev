OS kernel · Nov – Dec 2025 · 21 days

Monk OS: the agent is PID 1, not a chat plugin

Plan 9 / BeOS energy in TypeScript on Bun. Industry shipped similar agent runtimes months later. This one was purer about the OS metaphor.

  • Everything is a file and a DB record — schema, observers, ACL
  • HAL barrier: kernel never touches Bun directly · 2 runtime deps
  • Agent memory is first-class OS state, not a bolted-on vector store
