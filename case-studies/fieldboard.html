Seven crates. Seven days. Zero JavaScript.

Field Board is a real-time collaborative whiteboard built entirely in Rust — Axum and PostgreSQL behind, Leptos and WebAssembly in front, binary protobuf between — delivered as a Gauntlet AI Week 1 sprint. 511 commits, 49,900 lines across seven workspace crates, a full framework rewrite on day three, and a portfolio site that documents every commit.

The brief

One week. One whiteboard. Pure Rust.

Week 1 of the Gauntlet AI fellowship. The assignment: build a collaborative whiteboard with AI integration. The self-imposed constraint: do the entire stack in Rust with no JavaScript runtime. Not because it was easier — it was harder — but because the constraint was the point. A pure Rust stack meant Leptos SSR instead of React, protobuf instead of JSON over WebSockets, and a canvas engine that compiled to WASM with zero web-sys test dependencies.

The project documented its own constraints before writing code: 5–20 concurrent users, $100/month budget ceiling, WebSocket-mandatory real-time sync, seven-day window. The constraints doc preceded the design doc, which preceded the code.

Why the speed was possible

510 of 511 commits land in a single seven-day burst (February 16–22, 2026). The 511th is a lone dependency-policy commit from May. This isn't overtime or chaos — it's the builder knew the tools, wrote the plan first, and the scope was hard-bounded by a deadline that couldn't move.

The crate architecture

Seven members, each with one job.

The day 3 rewrite

React worked. It got deleted anyway.

Day 1 stood up the stack on React and Konva. It worked. Cursor sync ran, the AI drew shapes, persistence survived three rewrites in a single day. By the end of Day 2 the frontend had been gutted and rebuilt once already.

Day 3 killed React entirely. The morning built the canvas engine crate with 99 geometry tests and 55 state-machine tests. That afternoon, across eight sequential phased commits, React and Konva were ripped out and replaced by Leptos 0.8 SSR — a framework most Rust developers haven't touched. The React code had worked. It was deleted because it violated the constraint: a pure-Rust stack doesn't have a JavaScript runtime.

Mid-sprint framework rewrite

Replacing your frontend framework on day 3 of a 7-day sprint looks reckless. It wasn't. The canvas engine was already built and tested independently of any framework. The EngineCore has zero web-sys or wasm-bindgen dependencies — the entire geometry, hit-testing, and input state machine test suite runs on native Rust without a browser. The framework was the shell, not the brain.

The EngineCore split

Test without a browser.

The canvas crate is split in two: EngineCore is pure Rust with no platform dependencies. It handles coordinate math, shape geometry, rotation-aware hit testing, selection state, a 7-state input gesture machine, and 9 shape kinds. A thin WASM wrapper bridges it to web-sys and the browser Canvas API via a CanvasHost trait.

This split is what made 1,065 tests possible in seven days. Every geometry calculation, every state transition, every hit-test edge case runs as a normal cargo test — no headless browser, no DOM simulation, no test harness overhead. The WASM boundary is tested separately. The engine is tested exhaustively.

The canvas engine has 10,241 lines of Rust and zero browser dependencies. The framework rewrite on Day 3 didn't touch a single engine test.
Architecture

Four decisions worth stealing.

Ticket-based WebSocket auth. The server issues a one-time ticket on HTTP login. The client connects over WebSocket with that ticket. The server consumes it via DELETE ... RETURNING — replay-proof by construction. If the delete returns no rows, the ticket was already used or expired. No token store, no race window.

Dual-speed persistence. Board objects flush at 100ms intervals. The frame log — the full event stream for undo/redo and rewind — batches at 5ms. Two write speeds, tuned to their traffic patterns, sharing one PostgreSQL instance.

AI tool loop with live broadcast. The AI backend exposes 9 board-mutation tools (create, move, resize, group, style, etc.) to Claude or GPT-4 via a strict quoted-YAML grammar. Each tool call mutates the board and broadcasts the change to all connected clients in real time. The AI draws, and everyone watches.

Spatial-bucket viewport culling. Objects are bucketed spatially. Only objects in or near the viewport are rendered. Combined with RAF-coalesced redraws (Day 6), this keeps the canvas responsive at 1,000+ objects.

The cost of speed

$2,133 and 347 sessions.

The project logged its own AI spend via Cassio: 347 sessions, 855 million input tokens, 4.5 million output tokens, $2,133 total. 158 hours of wall time across parallel worktrees. Split roughly 64% Codex (implementation) and 35% Claude Opus (architecture and review).

Two custom agents were used: a "Rust Correctness Surgeon" for targeted fixes and a "Technical Writer" for documentation. The project's CLAUDE.md enforced no .unwrap() in production code, mandatory fmt→clippy→test→commit pipelines, and auto-commit with no permission-asking.

The project self-reports as ~99% AI-generated code. This is noted transparently, not hidden — and it's the point. The thesis isn't that a human typed 49,900 lines. The thesis is that a human directed a coherent system of that scale in seven days, and the system works.

Patterns

What the sprint reveals.

The rewrite as signal

Replacing React with Leptos on Day 3 of a 7-day sprint. The willingness to delete working code mid-deadline is a process signal, not recklessness — the architecture made it safe.

Test without the platform

EngineCore compiles and tests without web-sys. 10,241 lines of canvas logic verified by cargo test alone. The framework rewrite didn't touch a single engine test.

Constraint as liberator

Pure Rust, no JS runtime. The constraint forced better architectural decisions: protobuf over JSON, EngineCore/WASM split, Leptos SSR. Escape hatches produce mediocre answers.

Refactor day earns its keep

Day 5 added zero features. It decomposed modules, split CSS, restructured for the endgame. The final two days landed 138 commits without accumulating debt.

Document the receipts

AI spend, session count, token volumes, wall-clock hours, test coverage, dependency count. Every claim is a number. The portfolio site is the proof.

Velocity from bounded scope

Hard deadline, clear brief, constraints doc before code. The plan fit the window because it was shaped to. Speed came from discipline, not luck.

Field Board is not a side project. It's a stress test for a way of working — a seven-day proof that AI-assisted engineering can produce a real system with interconnected crates, a dependency-free engine, a mid-sprint framework rewrite, spatial rendering, real-time collaboration, and documented cost transparency. The velocity is the thesis, and the velocity is inspectable: every commit, every session transcript, every dollar is on record.

The portfolio site built on Day 7 isn't marketing. It's evidence — hand-curated from the actual git log, with raw transcripts attached, authored by the person who directed the sprint and can explain every architectural call. The speed came from the constraints being tight, the tools being ready, and the builder knowing when to cut.

Velocity is not chaos. It is what happens when the constraints are tight and the tools are ready.
